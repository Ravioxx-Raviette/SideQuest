# Wishlist Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans here and request final read-only review.

**Goal:** Save browser-local favorites and move them into the shopping bag safely.
**Architecture:** wishlist.js loads before app.js, supplies wishlistControl(product, compact), lazily initializes validated saved IDs after PRODUCTS is available, and manages view rendering and shared selection. Extend app routing with #wishlist and let addToCart return a success boolean.
**Tech Stack:** Existing HTML/CSS/JavaScript, localStorage, Playwright.
**Spec:** docs/superpowers/specs/2026-11-13-wishlist-design.md.

## Global Constraints
- Save only unique known product IDs under sidequest-wishlist-v1.
- Move one unit; remove favorite only after successful bag addition.
- Handle malformed/blocked storage and cross-tab synchronization.
- Preserve all earlier features; no dependencies or remote writes.

## Review Focus
- A full bag must not discard a saved favorite.
- Re-rendering the wishlist or deleting its modal opener must restore meaningful focus.
- Shared toggle state must survive filtering and quiz rerendering.
- Header/card layout must fit 320px screens.
- Cross-tab and invalid storage must not break initial routing.
